# DS AI/ML Python Tasks

This repository contains the tasks and practice exercises completed during the **DS AI/ML course**, with a focus on learning Python and applying it to data science and machine learning concepts.

## Repository Contents

- `ATM_Ajith.py` - Task 1: a basic Smart ATM exercise covering variables, arithmetic operations, comparisons, and output.
- `Pgp task1.pdf` - The task instructions for the Smart ATM exercise.

More course assignments and exercises will be added to this repository over time.

## Running a Task

Make sure Python is installed, then run the script from this directory:

```bash
python ATM_Ajith.py
```

The program calculates the balance after a withdrawal and demonstrates simple checks such as balance comparisons and denomination calculations.

## Learning Focus

The tasks in this repository are intended to build practical understanding of:

- Python syntax and variables
- Arithmetic and comparison operators
- Conditional logic and problem solving
- Data science and machine learning foundations
- Writing clear, executable coursework solutions
